# PentaGemma: 5-Sentence Summarizer
Hobby project.

**Objective**: Fine-tuning [Gemma 4](https://ai.google.dev/gemma/docs/core/model_card_4) for 5-sentence text summarization and comedic obsession with the number 5.

Done with the Gemma 4 E2B IT model, [UnSloth](https://unsloth.ai/), [a CNN / DailyMail dataset from Hugging Face](https://huggingface.co/datasets/abisee/cnn_dailymail), and "prompt engineering".

[Use it here!](https://huggingface.co/spaces/ianro04/PentaGemma)
